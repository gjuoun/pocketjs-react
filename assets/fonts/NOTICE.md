# Fonts

## NotoSansSC-reader-subset.otf

- **Font**: Noto Sans SC Regular, version 2.004, © 2014-2021 Adobe (http://www.adobe.com/).
- **Source**: `Sans/SubsetOTF/SC/NotoSansSC-Regular.otf` of https://github.com/notofonts/noto-cjk at commit `f8d157532fbfaeda587e826d4cd5b21a49186f7c`.
  - sha256 of the source font: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`.
- **Licence**: SIL Open Font License 1.1, reproduced in `LICENSE-NotoSansSC.txt`. The font declares no Reserved Font Name.
- **What this file is**: a subset (a Modified Version under the OFL), made with fontTools 4.67.0:

```sh
bun tools/fonts/make-cjk-set.ts
pyftsubset NotoSansSC-Regular.otf --text-file=assets/fonts/cjk-set.txt \
  --unicodes='U+0020-007E,U+00A0-00FF,U+2010-2027,U+2030-203A,U+20AC,U+2122' \
  --layout-features='' --no-hinting --output-file=assets/fonts/NotoSansSC-reader-subset.otf
```

- The command is reproducible: it gives sha256 `65f4cebede3fbd770b11f706f2c1930acd7753a7dab3f8631c916ad2fc0989e0` (2,068,732 bytes).
- **Use**: `tools/build-reader.ts --cjk` bakes the characters of `cjk-set.txt` into the reader's body font atlases with this font as the fallback face. The font file itself is not shipped in an app; its glyphs are, as atlas bitmaps.

## cjk-set.txt

Generated by `tools/fonts/make-cjk-set.ts` from the GB2312 and Big5 code tables (`--check` verifies it):
- line 1: GB2312 levels 1+2 ∪ Big5 level 1 = 8,836 hanzi, in codepoint order;
- line 2: CJK symbols and punctuation (without the combining tone marks U+302A–302F), full-width forms, CJK compatibility and small forms, and `─ ○ ★`.
